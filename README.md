# The-Little-Prince

#### A Python project using NLP and data visualization to explore The Little Prince’s emotional arcs, themes, and character relationships through sentiment analysis, topic modeling, and network graphs.

### Models used in the project:
##### - Emotional Arc Line Plot
##### - Changepoint Detection
##### - Topic Modeling Visualization
##### - Character Co-Occurance Network Graph
##### - Regression Models

### Key Results:
##### - Emtional Arc Analysis: Sentimental analysis revealed clear emotions flunctuations across the story, with trends that highlight major shift tones throughout the story.
##### - Text & Character Insights: Lexical feature analysis and word frequency visualizations showed that the Prince is the most frequently refrenced character, hence aligning with the story's narrative focus.
##### - Model Performance: Between the BernoulliNB, Logistic Regression, and SVM classifiers, SVM performed (75% accuracy), providing the most balanced predictions between positive and negative/neutral sentiment.
